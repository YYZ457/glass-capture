    从上电到对好焦
    
        
      
          
    1. 连接
      板子用 SD 卡启动，J83 接电脑。右上角「设备」选 Linux 控制台对应的串口 → 连接。看到登录界面或 U-Boot 时先用串口工具登录 root。
      2. 
          
    2. 初始化
      「设备」面板点「一键初始化」：唤醒终端 → 检查板卡 → 从 SD 卡加载程序和驱动 → 体检；相机还在双线模式时自动切到 Base 3 Tap / 16384。SD 卡根目录要有最新的 glass-capture 文件夹。
      3. 
          
    3. 验证链路
      相机属性 → 高级 → 测试图选「水平渐变」，点「单帧」：线轮廓是整齐的锯齿、8 个位全亮即链路正常。之后切回「关闭」。
      4. 
          
    4. 调亮度
      点「实时」。先加光、开光圈，再调曝光时间（不超过一行的时间）、数字位移、TDI。背景灰度 150–200、无饱和。
      5. 
          
    5. 对焦与调平
      放一条与扫描线垂直的黑白直边，拧对焦环使锐度最大、边缘宽度 ≤ 2 px；再换横跨视场的刻度尺，看 8 段锐度是否等高。两面都要检，最后把焦点推到玻璃厚度中间（1 mm 玻璃约 0.33 mm）。
      6. 
          
    6. 平场校正
      镜头、光源、行频、增益确定后：相机属性 → 平场校正，选用户组 → 暗场 → 亮场 → 启用。不保存，断电要重做。
      7. 
          
    7. 连续运行
      设置 → 驱动与程序切到「快速」DMA，再到「连续运行」开始。吞吐需达到 246 MB/s，且无队列满、无块号不连续。
      8. 
        
    
        
    完整步骤和排查见仓库 docs/BRINGUP.md。所有修改只改运行时的值，中控台不提供保存到相机的入口。
