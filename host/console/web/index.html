OPERATOR'S GUIDE
从连接到第一帧。
现在可以离线阅读。回到实验室后按步骤操作。
01 / 连接
板子由 SD 卡启动，J83 接电脑。刷新串口，选择 CP2108 的 Linux 控制台端口；过去为 COM10，但端口号可能变化。
先关闭其他占用此端口的串口软件，再点连接与唤醒。看到 root 提示符后执行检查板卡。
02 / 准备
检查板卡通过后，从 SD 卡加载已验证的程序。此步骤只读挂载 SD，拷入板上临时目录并加载驱动，不修改启动文件。
若出现登录界面或 U-Boot 提示符，暂不发自动命令；先用串口工具完成 Linux 登录。
03 / 检查与采集
相机供电、接线恢复后，检查采集条件。只有条件满足才尝试单帧采集。失败时保留日志，按阶段定位。
图像暂存在板子 /tmp，断电会消失。本版支持导入本地 PGM 查看，未实现大图自动回传与视频流。
04 / 阅读与维护
core 是核心源码，board 是此前验证过的板上文件，console 是中控台。编译结果进入 build/output，不自动覆盖 board。
当前工程独立于旧调试目录。旧测试与逆向记录保留在原处，日常操作无需翻找它们。
