# GC-CAL-01 标定玻璃板

80 × 105 × 1.0 mm 钠钙玻璃，单面低反射铬，按厂家 ±1 µm 精度级设计。版图由 `tools/calib_target.py` 生成，改设计只改那个脚本，再运行：

```
pip install gdstk ezdxf
python tools/calib_target.py
```

| 文件 | 用途 |
|---|---|
| `GC-CAL-01.gds` | 给厂家（图层 1 = 铬，图层 2 = 外形参考） |
| `GC-CAL-01_dxf.zip` | DXF 备用 |
| `GC-CAL-01_truth_mm.csv` | 真值：板坐标 mm（铬面朝上、从相机看；x 横跨视场，y 沿扫描方向） |
| `GC-CAL-01_zones.json` | 区段范围和参数 |
| `overview.svg`、`detail_*.svg` | 说明页用的示意图 |

圆在 GDS 里是正多边形，顶点按"面积相等"外放，每种直径的面积等效直径误差 < 0.001 µm（内接多边形会系统性偏小 0.6%）。

## 区段（y 沿扫描方向）

| 段 | y / mm | 内容 | 为什么少不了 |
|---|---|---|---|
| A | 0–10 | 空白 | 检测程序学每列阈值；照明均匀度 |
| S | 11–29 | 每 10 mm 一个单元：1 mm 宽条 + 3 mm 宽 40 lp/mm 细线，全部平行于长边 | 静态调焦：玻璃不动时相机只看到一条线，只有平行于长边的图案和它相交。单元对准中控台 8 段锐度 |
| B | 31–43 | 77 × 11 个 Ø0.2 mm 点，1 mm 间距；两端行每 10 mm 一个 Ø0.4 mm 大点；左上角方块 | 每像素多少 µm、畸变、扫描方向行长；配准的基准 |
| E | 45–85 | 2 / 5 / 8 / 10 / 15 / 20 / 30 / 50 µm 铬点，各 304 个；每行两端各一个 Ø0.1 mm 行标 | 检出率（≥ 300 个全检出 → 95% 置信 ≥ 99%）、尺寸、位置误差；5 / 8 µm 夹住产线焦点下的检出下限，2 / 5 µm 夹住焦点在铬面时的下限 |
| J | 87–94 | 3 mm 全铬黑条 + 板号 | 黑电平与杂散光；上沿是全宽横边 |
| T | 95–105 | 空白 | 手拿这一头；第二段干净背景 |

**为什么要行标**：玻璃速度不是绝对匀速，±5% 的起伏在离点阵尺 40 mm 的地方会累积出几百像素，而 V4 的配对半径只有 5 像素。每行两端各放一个 Ø0.1 mm 的点，配准时逐行就地定位。Ø0.1 mm 约 20 像素宽，和颗粒（≤ 10 像素）、点阵点（41 像素）都分得开。

## 不放进来的东西

斜边和线对（测"动起来多清楚"，验收不考）、近距对（验收没有这项）、铬划痕（铬线不透光，和真划痕两回事）、随机点（算法不利用网格规律）、透明颗粒窗口（微球会弄脏精密板，另用普通玻璃）。

## 精度：按厂家的 ±1 µm 级（推理见说明页）

1. **对验收够不够**：±1 µm 占直径公差 1/5（15、20 µm）到 1/10（50 µm），在计量"至少 1/4"的线以内；位置占 1/25；点阵尺比例误差 1.3 × 10⁻⁵，可忽略。→ 够用，不要求更高。
2. **不做 1 µm**：±1 µm 下可能做成 0–2 µm 或整颗没有，"没检出"分不清原因。2 µm 至少做得出点。
3. **±1 µm 不改变 2 / 5 / 8 µm 的结论**（仿真峰值，阈值 12.5 DN）：2 µm 做成 1–3 µm，焦点在铬面也只有 ≤ 7.3 DN，看不到；焦点在厚度中间时 4–6 µm 为 4.0–9.8 DN，看不到，7–9 µm 为 13.9–20.8 DN，看得到。焦点在铬面时 4 µm 落在像素交界处会降到 11.8 DN，所以 5 µm 的结果要对照实测直径。暗场下（亮度为假设值）3 µm 可能看到，2 µm 那排暗场结果也要对照实测直径。

→ 要补的只有 2 µm 的存在性和 5 / 8 / 10 / 15 µm 的实测直径：厂家报告或自己用显微镜量（50× 物镜 + 标准测微尺）。

## 给厂家的规格

| 项目 | 要求 |
|---|---|
| 基板 | 钠钙玻璃 1.0 mm（1.1 mm 可），不需要石英 |
| 外形 | 80.0 × 105.0 mm ±0.1，四边倒棱，边缘 1.5 mm 内无图形 |
| 膜层 | 低反射铬，光密度 ≥ 3 |
| 精度等级 | ±1 µm（位置和线宽 / 直径） |
| 最小特征 | Ø2 µm 圆点（只要求存在；做不出来就去掉这一排）、Ø5 µm 圆点、12.5 µm 线 |
| 缺陷 | 透光区无 ≥ 5 µm 铬残留 |
| 报告 | 2 µm 抽查 20 个是否存在；5 / 8 / 10 / 15 µm 各实测 5 个直径（加钱就不要，自己量） |
| 数量 | 2 块 |

## 拿到板子以后：扫描 → 配准 → 比对

```
python -I verify/plate_register.py scan.pgm --out truth_px.csv --roi roi.json --report report.json
python -I verify/V4_truth_match.py candidates.json truth_px.csv --roi roi.json
```

- 扫描用明场（背光），整板一次短录。配准要 numpy 和 scipy。
- 翻面、掉头都不用手改坐标，配准自己认，屏幕上会写"铬面朝上 / 朝下，A 端 / J 端先进"。
- 配准顺便报：每像素多少微米（左、中、右）、畸变、旋转、扫描方向一行多长，以及要变成正方形像素速度该乘多少。
- `--roi` 让 V4 只数颗粒区里的误报；点阵、行标、调焦条、黑条都在区外。
- 板长 105 mm，两端搭着中间下垂约 6.5 µm，在景深 ±65 µm 内。
