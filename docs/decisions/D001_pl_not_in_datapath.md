# D001 · PL 暂不进入数据通路

**状态**：生效（2026-11-06）

**事实**：目前的采集链路是 ZCU102 的 ARM（PS）跑 Linux，经 PCIe 读 SG3000 卡。仓库里没有 bitstream、没有 Vivado 工程、没有 PL 内核驱动。`fpga/` 里的 HLS IP 只做过综合和仿真；预处理 IP 综合结果约 22 Mpx/s，需要约 252 Mpx/s，差约 11 倍。

**决定**：

1. 验收要的是"检得出、检得准"，不是"在 FPGA 上检"。先在 ARM 或电脑上把检测跑通、对上真值。
2. `fpga/` 原样保留、不细分，`board/processing/sg_pl_backend.c` 不迁移。
3. 和导师、公司汇报时说"ARM + PCIe 采集"，不说"FPGA 采集"。

**什么时候重新考虑**：ARM 上的检测实测跟不上行频，且 D002 要求板上实时处理时。
