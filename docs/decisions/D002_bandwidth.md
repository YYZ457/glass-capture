# D002 · 带宽预算决定架构

**状态**：生效（2026-11-06，2026-11-07 更新）

| 环节 | 数值 |
|---|---|
| 物方像素 | 80 mm / 16384 ≈ 4.88 µm |
| 行频 | 75 mm/s ÷ 4.88 µm ≈ 15.36 kHz |
| 原始数据率 | 16384 × 15.36 k × 1 B ≈ **252 MB/s** |
| Camera Link Base（单线）| 85 MHz × 3 tap = 255 Mpx/s |
| Camera Link EightyBit（双线）| 85 MHz × 10 tap = 850 Mpx/s |
| PCIe（实测链路 5 GT/s ×1）| 约 4 Gb/s ≈ 500 MB/s；卡本身支持 16 Gb/s，被 ZCU102 插槽限制 |
| 千兆网 | ≈ 110 MB/s |
| 现在的串口 | 一帧约 7 分钟 |

## 结论

1. **单线 Base 跑不满 75 mm/s**：3 tap 传一行 16384 像素要约 5462 个时钟，15.36 kHz 下每行预算约 5533 个，只剩约 71 个做行消隐（1.3%）。实际相机通常需要更多。
   - 相机只支持 Base 和 EightyBit 两种配置（相机 XML [参考8K]），没有中间档
   - 要么降速：约 60 mm/s → 12.3 kHz、201 Mpx/s，Base 有约 20% 余量
   - 要么上双线：需确认 SG3000 支持 EightyBit、有第二根线，且 PCIe ×1 的 500 MB/s 仍够用
2. **满速原图出不了板子**（252 MB/s > 千兆网 110 MB/s）→ 最终在板上检测，只发候选（`processing/sg_candidates`、`transport/tx_tcp`）。
3. 调试阶段降速或抽样传原图，网口足够。

**验收只要求 30 µm 以下**（约 6 像素宽）。需要和导师确认：验收时速度是否必须 75 mm/s。若可以降速，单线 Base 即可。
