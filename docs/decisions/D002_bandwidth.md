# D002 · 带宽预算决定架构

**状态**：生效（2026-11-06）

| 环节 | 数值 |
|---|---|
| 物方像素 | 80 mm / 16384 ≈ 4.88 µm |
| 行频 | 75 mm/s ÷ 4.88 µm ≈ 15.4 kHz |
| 原始数据率 | 16384 × 15.4 k × 1 B ≈ **252 MB/s** |
| Camera Link Base 上限 | ≈ 255 MB/s（85 MHz × 3 tap，待手册确认）|
| 千兆网 | ≈ 110 MB/s |
| 现在的串口 | 一帧约 7 分钟 |

**结论**：

1. 满速原图出不了板子 → 最终必须板上检测，只发候选（`board/processing/sg_candidates`、`board/transport/tx_tcp`）。
2. 调试阶段可以降速或抽样传原图，网口足够。
3. Camera Link Base 可能刚好卡在上限 → 先查清相机实际配置（I1），这可能决定能不能跑满 75 mm/s。

**验收只要求 30 µm 以下**，约 6 像素宽。如果允许降低分辨率或速度，以上压力都会大幅下降，值得和导师确认验收时的速度要求。
