## 带宽核算（必须先算清，否则 16K 可能根本跑不到目标行频）

16384 × 15.4 kHz ≈ 252 Mpx/s。Camera Link Base 一般为 85 MHz × 最多 3 tap（8 位）≈ 255 Mpx/s，**刚好卡在边上**。
Medium/Full 有余量，但需要双线缆。此结论要用相机手册确认。

## 怎么填这张表

1. 相机手册：查支持的配置、tap、像素时钟、测试图案
2. Windows + VisionKit：读出相机当前配置
3. 没有镜头也能判断宽度：遮住传感器左半边采一帧 —— 每行都有明暗分界 → 输出 4096；每 4 行一组明暗交替 → 相机发 16384、卡按 4096 切行
